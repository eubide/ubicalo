# Etiquetas de triage

Los skills hablan de cinco roles canónicos de triage. Este archivo traduce cada rol a la etiqueta real del issue tracker de este repositorio.

| Etiqueta en mattpocock/skills | Etiqueta en nuestro tracker | Significado                                                   |
| ----------------------------- | --------------------------- | ------------------------------------------------------------- |
| `needs-triage`                | `needs-triage`              | Hay que evaluar el issue                                      |
| `needs-info`                  | `needs-info`                | Esperando más información de quien lo abrió                   |
| `ready-for-agent`             | `ready-for-agent`           | Totalmente especificado, listo para un agente sin supervisión |
| `ready-for-human`             | `ready-for-human`           | Requiere implementación humana                                |
| `wontfix`                     | `wontfix`                   | No se va a hacer                                              |

Cuando un skill mencione un rol (p. ej. "aplica la etiqueta de listo para agente"), usa la etiqueta de la columna de nuestro tracker.

Edita la columna derecha si cambias de vocabulario.
